# De Pátria para Pátria

Uma página responsiva da TripleTen Art Gallery que apresenta histórias de
pessoas de diferentes partes do mundo e suas cidades natais.

O projeto foi desenvolvido para reproduzir o layout fornecido nos formatos de
desktop, tablet e celular, com foco em organização de código, semântica e
acessibilidade.

## Tecnologias e técnicas utilizadas

- HTML5 semântico
- CSS3
- Metodologia BEM
- Flexbox
- Media queries para layouts de 1280px, 768px e 320px
- Fonte Inter carregada localmente com `@font-face`
- Imagens SVG e favicon
- Normalização de estilos com Normalize.css
